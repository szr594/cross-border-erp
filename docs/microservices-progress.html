当前原则

保留 backend 作为可运行基线，任何旧模块只有在新服务功能和测试全部对齐后才清理。

数据边界

本地可共用一个 MySQL 8.4 实例，但每个服务拥有独立数据库，禁止跨服务直接查询数据表。

一致性方式

服务内使用本地事务；跨服务通过 RabbitMQ、Outbox 和幂等 Inbox 完成最终一致性。
